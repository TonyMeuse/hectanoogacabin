# Hectanooga Lake Adventure Cabin

Sample direct-booking website for Hectanooga Lake Adventure Cabin, a 12 × 20 off-grid rental cabin.

This is a **sample version** for review:
- Owner dashboard (demo password `cabin`) edits price, description, photos, calendar and bookings. Changes are saved in the viewer's browser only.
- Checkout is simulated. No card is charged.

The production version will add a server-side database, secure owner login, Stripe payments, and the owner's own domain name.
